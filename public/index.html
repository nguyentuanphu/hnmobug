Gameplay

A world to explore together.

Build a character

Cast spells as a Dark Wizard, fight up close as a Dark Knight, or play a Fairy Elf with ranged attacks and party support. Level up to learn skills and take on class-change quests.

Hunt, upgrade, and craft

Fight monsters for gear and materials. Visit the Chaos Machine in Noria to check recipes and success rates before mixing equipment or wings.

Play together

Level with a party, join a guild for Castle Siege, or take on Blood Castle and Devil Square. The game site shows event times and rankings.

Seasons and Arena

Start with Season 6.3. Enable Season 9 or Arena in Host settings and restart HNMO when you're ready. Arena offers ranked 1v1 duels and 5v5 team battles.

Download HNMO and start your server.

One download includes the browser game, server, and admin panel for all three host platforms. Start free with up to 10 players online at once.

Download HNMO free Read the step-by-step guide
Windows 64-bit
  1. Extract HNMO.zip. PostgreSQL is bundled.
  2. Double-click Start HNMO.bat. Use the tray icon to open the game, open the admin panel, or stop HNMO.
macOS Apple Silicon · Intel
  1. Extract HNMO.zip and install PostgreSQL 16, for example with Homebrew.
  2. brew install postgresql@16
  3. Open Terminal in the HNMO folder and run the launcher below.
  4. ./start-hnmo.sh
Linux x86-64
  1. Extract HNMO.zip and install PostgreSQL 16. The command below is for Ubuntu releases that provide the package.
  2. sudo apt install postgresql-16
  3. Open a terminal in the HNMO folder and run the launcher.
  4. ./start-hnmo.sh

After launch

  1. Open the game

    Allow a few minutes for the first run to create your save data. When ready, open localhost:8080 on the host.

  2. Create an admin account

    On the host, open localhost:8095, go to Users, and create the first admin account.

  3. Keep your progress

    Progress lives in the save folder. On the host, localhost:8080/control provides logs, backups, and shutdown controls.

Support

What to check when the game fails to start or players cannot connect.

Where do I check a startup problem?

Allow a few minutes for first launch. On the host, check localhost:8080/control or the save/logs folder. If the host can play and another computer cannot, verify the shared address and that computer’s network connection.

Where do I review player bug reports?

On the host, open Bug reports in the admin panel to review player submissions. When forwarding a report, include the version, where the issue happened, and the steps that reproduce it.

What does the server share with HNMO?

Builds with hub reporting send system and game configuration details on first setup. HNMO records the source IP and country for that report. Periodic reports include usage totals, errors, and bug reports the host forwards.
