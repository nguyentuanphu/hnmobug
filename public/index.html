Windows setup

Download. Extract. Play.

The Windows download bundles the server, browser game, admin panel, and database. Start free with up to 10 players online at once.

  1. Download and extract

    Download the Windows package to one PC and extract the ZIP into an HNMO folder.

  2. Open Start HNMO.bat

    Double-click the launcher. On the first run, HNMO takes a few minutes to prepare your save data and then opens the game site in your browser.

  3. Set up admin and invite players

    On the host PC, open the panel at localhost:8095 to create your first admin account. Share the game address and keep HNMO running while people play.

What does the server share with HNMO?

Builds with hub reporting send system and game configuration details on first setup. HNMO records the source IP and country for that report. Periodic reports include usage totals, errors, and bug reports the host forwards.
