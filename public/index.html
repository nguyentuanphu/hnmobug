Windows setup

From download to your own world.

  1. Download and extract

    The Windows package includes the server, web client, admin panel, and database.

  2. Start HNMO

    Open Start HNMO.bat and let it prepare the save data. Then create your first admin account on the host machine.

  3. Invite players

    Share your HNMO address on your local network or configured remote connection. Players join in their browser.

Licences and support

Start small. Add capacity as you grow.

The download supports up to 10 concurrent players without a licence. If you need more room, contact HNMO or send a request from your server if your build offers that option. The HNMO owner issues the licence.

View licence packages
How do I install a licence?

Place the issued license.hnmo file beside the launcher and restart HNMO. The server log shows your new player limit.

Where do I report a bug?

Forward reports through your server if your build supports it, or use the HNMO issue tracker. Include where it happened, how to reproduce it, and the version you're running.

Open the HNMO issue tracker

What does the server share with HNMO?

Servers with hub reporting send system and game configuration details on first setup. The hub records the source IP and country for that report. Periodic reports include licence status, usage totals, errors, and bug reports the host forwards. Automated reports do not collect player usernames, email addresses, or passwords.
